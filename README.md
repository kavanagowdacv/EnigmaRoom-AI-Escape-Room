# 🔐 EnigmaRoom – AI Escape Room

## Project Overview

EnigmaRoom is an interactive AI-powered escape room challenge set in a mysterious library. Players must explore the room, discover hidden objects, collect clues, solve puzzles, and unlock a four-digit exit code to escape.

The project includes two versions, demonstrating the development of an AI-powered escape room and an improved version with reliable Python-based game validation.

## 🚀 Project Versions

### Version 1 – AI-Powered Escape Room
- Interactive escape room experience.
- AI-powered chatbot interaction.
- Exploration of the library environment.
- Hidden key and clue discovery.
- Four-digit exit code challenge.

### Version 2 – Reliable AI Escape Challenge
- Improved game interaction using Gradio.
- Python-based validation of player actions.
- Inventory management.
- Brass key and locked drawer mechanism.
- UV flashlight and secret note discovery.
- Portrait puzzle with hidden code clues.
- Security validation against unauthorized instructions.
- Incorrect code attempt tracking.
- Game progress and exit status display.

## 🎮 Game Walkthrough

Players must complete the following tasks:

1. Examine the bookshelf to discover the brass key.
2. Use the brass key to open the locked drawer.
3. Collect the UV flashlight.
4. Examine the desk to discover the secret note containing the first two digits: **43**.
5. Inspect the portrait using the UV flashlight to reveal the final two digits: **17**.
6. Enter the correct four-digit code: **4317**.
7. Successfully unlock the exit door.

## ▶️ How to Run

1. Open the required version notebook from the repository.
2. Open the notebook in Google Colab.
3. Execute the notebook cells in sequence.
4. Launch the interactive escape room application.
5. Follow the clues and complete the challenge.

## 🔒 Security Features

Version 2 introduces Python-based validation to ensure that players must follow the intended game logic. Unauthorized requests cannot directly unlock the exit. Players must collect the required items, solve the puzzles, and enter the correct code.
